LocalVersus2 entrance implementation

Open Assets/Remaster/Scenes/LocalVersus2.unity, or use Remaster > Open LocalVersus2 entrance scene, then press Play. The scene starts with manual Jin (P1) versus Kazuya (P2). It shows Jin's entrance shot, Kazuya's entrance shot, a face-off, READY, then FIGHT. Enter skips the sequence. The existing controls apply after FIGHT. The match timer and combat simulation remain stopped through the entrance.

The extracted cooked scripts identify distinct OnCharacterEntrance, OnOpponentEntrance, OnBattleBegin, and OnRoundActionStart events in some original game components (for example the exported functions of BP_mig_exp_apple). They do not provide a readable complete sequence or converted Jin/Kazuya intro cinematics. This scene implements that event order as a new Unity presentation using the current imported fighters and idle motion. Shot length and movement are provisional and should be matched to direct original game capture before describing them as exact Tekken 7 timing.

Build menu: Remaster > Build LocalVersus2 Windows player. Output: Builds/LocalVersus2/LocalVersus2.exe.
