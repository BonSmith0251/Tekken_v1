COMBAT POSE CONVERTER - ROTATION FIX v3

Open Unity > Remaster > Combat pose converter preview.
Close and reopen an existing preview window to load the rebuilt samples.
Select idle, walking, crouch, left/right punch, or left/right kick; Play or scrub
Frame. Create Unity AnimationClip exports the pose shown in the preview.

The body twist was caused by interpreting compressed 0x64 spherical axis-angle
values as Euler angles. Version 3 reconstructs the rotation axis and quaternion,
converts to the C8 convention, and transfers through the established reference
rig into Jin's local bone transforms. The bundled profile uses this mapping
without fitting an unrelated inter-round stance. No joint clamps or smoothing
were used to hide the old twists. Fast attack extensions remain in the data.

All eight bundled clips were rebuilt. The 1,514 compressed sources in the Unity
OriginalMotions library were also regenerated with the corrected C8 rotations.
Native source files are preserved. Original C8 clips use their existing format.
The converter still needs a frame-by-frame comparison against original gameplay;
body motion does not include the separate finger/facial animation banks.
LocalVersus gameplay is not changed by this editor fix.

IMPORTANT FOR OLDER EXPORTS
Previously exported .anim/.bytes files do not repair themselves. Reconvert and
export new clips. Recreate custom calibration profiles made before v3. The old
bundled calibration.json is retained; the converter now uses calibration-v3.json.

CONVERT ANOTHER CLIP
1. Open Remaster > Combat pose converter.
2. Browse for the original .anim/.t7native, or a newly decoded .c8 motion.
3. Select calibration-v3.json and choose in-place or source root movement.
4. Click Convert motion and save under Assets with a new name.
5. The 3D preview opens; play, scrub, and export a Unity AnimationClip.
The Python path defaults to C:\Python311\python.exe. NumPy and SciPy are required.
Existing outputs and reports are protected; choose a new filename.

OPTIONAL POSE ALIGNMENT
Expand Create a calibration, choose a source reference motion and frame, then
choose a JRT target clip and frame. Alternatively pose Jin in a scene, select his
root, and Capture selected Jin pose. Create calibration profile saves a new
profile and selects it. Frame numbers start at zero. This optional alignment
changes the reference pose; the default v3 mapping does not need it.

COMMAND LINE (from Tools/CombatPoseConverter)
  C:\Python311\python.exe combat_pose_converter.py --help
  Reconvert clips.cmd
The latter rebuilds the eight samples using calibration-v3.json. Close and reopen
the preview after rebuilding. New conversion reports include source/profile
hashes and maximum one-frame rotation. Large steps at punch/kick extension are
reported, rather than automatically smoothed.

VALIDATION
Validation/combat-pose-converter.json: Unity preview/export checks.
Validation/combat-converter-window.json: pose capture, calibration and conversion.
Validation/combat-twist-landmarks.json: body and support-foot checks on every
frame of the eight clips. Validation/CombatPoseLab contains rendered examples.
Tools/CombatPoseConverter/test_combat_pose_converter.py contains converter tests.

Reference rig mathematics are included from the existing BlenderTekkenDirect
research: https://github.com/Kiloutre/BlenderTekkenDirect
The spherical rotation correction was checked against the installed game's
quaternion construction at RVA 0x7308D2 through 0x7309F6.
