ORIGINAL STAGE LIGHTING: stg29
============================
Target: the night-ocean stage matching the supplied Jin/Kazuya reference video.
Source: installed TEKKEN.7 archives, read only. No live game process was available.
This is cooked asset data, not a live measurement or original C++ source code.

All three Chara lights explicitly use LC_CHARA_BOTH and disable shadows.
The environment light does not serialize LightChannel or CastShadows; these are
inherited/default values, not evidence for a particular channel or shadow flag.
All four are movable. They attach to far_light_0.DefaultSceneRoot. The map contains
BP_MugenFarLight, which references this light group and has tick/initialization
logic. These are relative asset rotations, not measured live world rotations.
Environment-light shadow distance: 4000 Unreal centimeters (40 m).

GLOBAL POST PROCESS
Explicit overrides with explicit serialized values:
- Auto exposure min brightness = 1, max brightness = 1 (locked exposure limits).
- Bloom intensity = 0.2; size scale = 3.
- Bloom tints 1/2/3: RGB 0.005 / 0.02 / 0.1, alpha 1 (linear).
- Lens flare intensity = 0.
- LPV intensity = 0.
- Ambient occlusion radius = 60, power = 5 (native parameter values).
- Screen-space reflection intensity = 70 (native scale).
AO intensity and SSR quality/max roughness have enabled override flags but their
values are omitted; native defaults still need resolving before exact porting.
DOF and motion-blur values also exist in the package, but their override flags
are not serialized. Do not treat all stored post-process values as active.

FOG
FogDensity = 0 and bVisible = false: disabled in this stage asset.
Stored inactive parameters: height falloff 2; start distance 1200 cm (12 m);
height 100 cm (1 m); linear scattering RGBA (0.041924,0.039375,0.075,1).

CHARACTER POST EFFECT / DYNAMIC CONTROL
Normal CharacterPostEffect: Fresnel color linear (0.5,0.66733,1,1), exponent 2,
intensity 0, direction sharpness 1.1, suppression 0.7.
The RageAttack override contains Fresnel intensity 60; it is not the normal state.
BP_LightControl has FilmSaturation 0.2 / FilmContrast 1 as control parameters and
KO/Rage timelines. They are not classified here as always-active global grading.
Blueprint defaults and source object/property offsets are preserved in the full
JSON for investigating these changes later.

HDRP PORTING IMPLICATIONS
- Replace generic two-light illumination with the three character-only lights
  plus the environment light, using HDRP light layers to isolate the fighters.
- Use the original HDR sky capture, with coordinate/face orientation verified.
- Disable the current generic stage fog to match this reference's base setup.
- Preserve locked exposure behavior; UE brightness 1 is not asserted to be HDRP EV 0.
- Native light intensity, bloom, SSR and AO values need renderer-specific mapping;
  the numbers above are not claimed to be calibrated HDRP lux or effect strengths.
- Convert Unreal axes/rotations and account for the moving parent before applying.
