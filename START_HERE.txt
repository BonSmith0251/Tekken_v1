TEKKEN VERSUS REMASTER - UNITY WORKSPACE

PROJECT LAYOUT
Assets/_Project/Characters/<Name>/  one folder per fighter
    (Jin, Kazuya, Xiaoyu, Alisa, Katarina, Lidia, Bob, Leo)
    Source/     extracted inputs the importers read (Base, Costumes, Wardrobe, Motion)
    Costumes/   imported outfits (materials, meshes, prefabs, textures)
    Wardrobe/   imported wearable items; Jin's Base/ is his original versus import
    Jin/Motion, Jin/References   Jin's decoded and retargeted motion libraries
Assets/_Project/Shared/Textures/    textures used by more than one fighter
Assets/_Project/Stages/Source/      extracted stage geometry (stg00-stg32 and variants)
Assets/_Project/Scripts/Runtime, Scripts/Editor
Assets/_Project/Scenes, Resources, Museum, Wardrobe, Rendering, Settings
Docs/  feature notes (battle, HUD, effects, sound, museum, staging, wardrobe, HDRP...)
Tools/, References/, Validation/, Skills/  pipeline tools, extracted references, checks

Open with Unity 2023.2.22f1. Double-click Open in Unity.cmd.

WHAT TO OPEN
LocalVersus2.unity   the versus match: character select, VS screen, original HUD and
                     round calls, the fighters' own movesets and command lists, impact
                     effects, camera, sound and music. Press Play. Controls and what is
                     original are in Docs/ORIGINAL_COMMANDS.txt; F1 shows the command list.
CharacterMuseum.unity   browse every fighter's outfits, moves and entrances (Docs/CHARACTER_MUSEUM.txt)
Wardrobe.unity       try on items, change colours, choose the items every other scene uses
                     (Docs/WARDROBE.txt)
staging_test.unity   plays each fighter's entrances and victories with the original
                     cameras (Docs/STAGING_TEST.txt)
env_scene.unity      choose which original stage versus uses
BattleEffectTuning.unity, BattleCameraShowcase.unity, CharacterEffectsShowcase.unity
                     tuning and showcase scenes for effects and cameras
The first LocalVersus scene was retired on 2026-10-27; use LocalVersus2.

BUILDS
Builds/ is empty at the moment. To build the player, create the file Temp/build-localversus2
in the project while Unity is open (its content is the output folder; empty means
Builds/LocalVersus2). A build is about 7 GB, so check free space on D: first. Play LocalVersus2.cmd
starts Builds/LocalVersus2/LocalVersus2.exe; Open Character Museum.cmd starts a museum
build if you make one in Builds/Museum.

CHECKS
Validation/ holds the results of the automated checks (command graph, sound, effects,
wardrobe captures, HDRP, stages). The Claude skills in ~/.claude/skills (tekken-versus-battle,
tekken-versus-ui, tekken-stage-environments, tekken-sound, tekken-costume-wardrobe) describe
how to re-run each one; tekken-versus-battle has a compile check and headless battle harnesses.

EXTRACTED DATA
References/ExtractedVersus contains the 8,094 extracted Unreal function bytecodes,
metadata and indices. These are references, NOT Unity C# scripts. The native Tekken
combat implementation has not been recovered; the remaster runs the game's own move data
instead (References/CommandGraph, Assets/_Project/Resources/CommandGraph).
Cooked .uasset/.umap copies remain at the path in Tools/source-paths.json.
Do not drag those cooked packages into Unity expecting them to run.
Edit Tools/source-paths.json if you move the original game or tool.
