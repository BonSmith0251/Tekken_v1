Each fighter's own wired effect plays in versus alongside the common hit/guard/KO set (on in
LocalVersus2, see BATTLE_EFFECTS.txt). Every fighter uses the same recovered native path: move property
0x802E plays manager effect ID 0 on the acting fighter's own bone (VBN bone ID = property value),
on that move frame, hit or whiff. Jin: JIN_BATTLE_EFFECTS.txt. Katarina: KATARINA_BATTLE_EFFECTS.txt.

Regenerate one fighter (<code> kaz|xia|asa|ltn, <Name> Kazuya|Xiaoyu|Alisa|Katarina; workspace root, then project):
  python %USERPROFILE%/.codex/skills/tekken-character-battle-effects/scripts/inspect_character_effects.py --workspace . --character <code> --out Artifacts/BattleEffects/<Name>Skill/v1 --extract --include-unbound
  python Tools/CharacterEffects/export_character_effects.py --evidence ../../Artifacts/BattleEffects/<Name>Skill/v1 --t7extract ../../t7extract --out Assets/_Project/Resources/CharacterEffects/<code>
  python Tools/CharacterEffects/dispatch_character_manifest.py --workspace ../.. --character <code> --manager-evidence ../../Artifacts/BattleEffects/<Name>Skill/v1 --out ../../Artifacts/BattleEffects/<Name>UnityUpdate
  python Tools/CharacterEffects/dispatch_bone_attachment.py --workspace ../.. --out ../../Artifacts/BattleEffects/<Name>UnityUpdate/dispatch-bone-attachment-proof.json
  python Tools/CharacterEffects/install_native_dispatch.py --character <code> --evidence ../../Artifacts/BattleEffects/<Name>UnityUpdate --project .
  Re-exporting resets registry.json; always run the installer after it.

Exporter changes for these fighters: manager bindings outside the character folder (Kazuya's
story-mode beam ground hit, Alisa's Common bomb and punch) are listed in registry.json
unconvertedBindings instead of stopping the export; a package name found twice in the closure
(Alisa's PS_EF_asa_punch_korea, in her folder and in Common) is left out of the short-name index
and still fails if anything references it.

Rendering adaptation: alpha-less colour textures (T_EF_COL_*) in character libraries take coverage
from their brightest channel and keep their hue (CascadeParticle _MaskKeepsColour, set by
CascadeEffects for CharacterEffects/ folders). Grey masks render exactly as before; the common and
stage libraries are unchanged. Before this, Alisa's swirl drew as white discs and Kazuya's
lightning as faint white specks. The original material's opacity rule is not recovered.
